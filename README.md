# VampireSurvivors（类幸存者游戏）

一个使用 **C++ 与 Qt Widgets** 开发的类 Vampire Survivors 风格的 2D 游戏项目，  
作为《高级程序设计》课程的综合实验，重点体现 **面向对象程序设计思想** 与 **中小型项目结构组织能力**。

---

## 一、项目背景与目标

本项目来源于高级程序设计课程的综合实验，目标不是简单完成“能跑的程序”，  
而是在一个**相对完整的游戏场景**中，综合运用课堂所学的：

- 面向对象设计（OOP）
- 多类协作与模块划分
- 状态管理与游戏循环
- Qt 框架下的事件驱动与资源管理

项目以类幸存者（Survivor-like）游戏为原型，实现了角色成长、敌人刷新、技能升级等核心玩法。

---

## 二、核心功能实现

### 1. 角色与操作系统
- 使用 **键盘事件** 控制角色移动
- 角色具有基础属性（生命值、攻击方式、等级等）
- 通过经验值系统实现 **角色升级与成长**

### 2. 战斗与怪物系统
- 不同类型的怪物（如蝙蝠、骷髅、恶魔等）
- 怪物具有独立的属性与行为逻辑
- 随游戏进程推进，怪物强度逐步提升（数值成长）

### 3. 技能与武器系统
- 多种武器 / 技能类型（火焰、冰冻、闪电等）
- 武器子弹与攻击效果独立封装
- 技能可随等级提升进行强化或扩展

### 4. 经验与升级机制
- 击败怪物后掉落经验道具
- 经验累计触发升级
- 升级后可影响角色属性或技能表现

### 5. 商店与交互
- 简单的商城 / 交互界面
- 使用 Qt Widgets 构建 UI
- 通过对话框或场景切换完成交互流程

## 四、程序设计方法与结构组织

### 1. 面向对象设计（核心）

项目大量使用 `class / struct` 进行建模，例如：

- `Survivor`：玩家角色
- `Vampire / Bat / Skeleton`：不同敌人类型
- `Weapon / Bullet`：武器与攻击逻辑
- `GameController / GameData`：游戏状态与流程控制

通过 **继承、组合与职责划分**，降低模块之间的耦合度，使逻辑更加清晰。

### 2. 模块划分思路

- **逻辑层**：角色、怪物、武器、数值计算
- **控制层**：游戏流程、状态切换、事件响应
- **表现层**：Qt Widgets 场景、UI、资源加载

各模块之间通过清晰的接口交互，避免“全局乱调”。

### 3. Qt 特性使用

- Qt 事件系统（键盘输入）
- Qt Widgets 构建界面与场景
- Qt Resource System（`.qrc`）统一管理图片等资源
